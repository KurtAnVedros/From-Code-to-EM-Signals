This folder contains all the code for the experiments done for "From Code to EM Signals" paper.

This repository is organized as follows:
0_Converting CSV to Numpy: Read the original csv files obtained from the digitizer oscilloscope. Then, the signals are disected for the interested program. Note that the programs are surrounded by nopes to avoid any complications of outside interference not related to the program of interenst. Once the program is identifyed, the full program signals are extracted and saved as numpy files.
1_Creating Dataset to Train ResGANs: These files anyze the common sequences in the training programs. First the instructions are identified inside the code based on the amount of cycles each instruction takes. Next, the common sequences are mapped. Afterwords, the sequences are extracted from the full signals. Next, the dataset for training the model is created by paring the code for the sequence with the extracted signals for said sequence. Note, for this paper we take only the peaks rather than the full signal to improve accuracy for these critical areas; however, the ResGAN model can learn to generate full signals.
2_Creating-Training ResGAN Model: These files contains codes for the ResGAN model. The full version trains on the dataset created prior from the training programs that contains all code seen in the program attempting to be generated. The 90 version has a ResGAN model trained on only 90\% of the code seen in the program attempting to be generated.
3_Manual Stich Method: Create a manual stitching methods of instructions for comparision in the paper. Showcasing that a simple manual method of a library of one instructions wouldn't create high fidelity synthetic signals.
4_ Comparing Similarities RealvsSynth: Contains code to compare the generated signals with the real varients by performing Euclidean distance comparison across the dataset of real compared other real and to the synthetic versions.
5_Additing White Gaussian Noise: Create noisy versions of the real signals for later anomaly detection testing. Note, WGN is what is seen in real enviornment scenarios.
6_Anomaly Detection/sub: These files contains results when attempting to detect a one instruction injections of a subtract assembly instruction. The test includes anomaly detection kNN method when training on real and another when training on synthetic when at SNR 25, 20 and 15. Additionally, there is anomaly detection autoencoder method when training on synthetic signals.
Dataset: contains all the dateset for the experiments. However, you will need to download them from the OneDrive link: https://1drv.ms/f/c/86d32251763ade23/EiPeOnZRItMggIbSEwAAAAABMrsjO6mWc_1lgB8lV54I5w?e=ziODXy
IO: files used for simple reader and writer instructions.
Modules: behind the scenes code for testing algorithms such as kNN, LOf, Evaluations metrics such as AUC and confidence estimation, methods to create graphs, and methods to identify code sections inside an EM signal quickly.
